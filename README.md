# :snowflake: SmartFridge :ice_cube:

SmartFridge is an ESP-powered <a href="https://shop.m5stack.com/products/m5stack-cores3-se-iot-controller-w-o-battery-bottom">M5Stack CoreS3 SE</a> combined with a <a href="https://shop.m5stack.com/products/2-channel-spst-relay-unit">M5Stack 2-channel relay</a> and a Ruuvi Bluetooth temperature sensor, that autonomously switches on our fridge in our van or to be more precise, turns the compressor of the fridge on and off, according to the settings chosen.
